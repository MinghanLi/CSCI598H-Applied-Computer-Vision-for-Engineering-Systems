# CSCI 598H: Applied Computer Vision for Engineering Systems

This course provides a comprehensive, application-driven introduction to computer vision and deep learning. It progresses from optimization, neural networks, and core vision tasks to modern topics such as self-supervised learning, foundation and generative models, 3D vision, and robotic perception. The course emphasizes applying these methods to real-world engineering and scientific challenges, including remote sensing, mining, energy, climate, and healthcare.
